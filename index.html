Fotos e velocidade do catálogo

Novas fotos serão armazenadas separadamente. O catálogo usa miniaturas; as fotos maiores aparecem ao abrir o produto.

A migração baixa uma cópia de segurança antes de começar. Mantenha esta página aberta até terminar. Se interromper, clique novamente para continuar os produtos pendentes.

Configurar armazenamento das fotos

No console do Firebase, abra o projeto lojaddtudo-bb639 → Storage. O serviço exige o plano Blaze, com cobrança conforme o uso. Crie o bucket lojaddtudo-bb639.firebasestorage.app e configure as regras abaixo. Se já houver regras, integre esta permissão às existentes. A primeira publicação pode solicitar a integração entre Storage e Firestore.

Envio permitido somente às contas cadastradas na coleção admins. As fotos do catálogo são públicas.

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /catalogo/{uid}/{productId}/{fileName} {
      allow read: if true;
      allow create, update: if request.auth != null
        && request.auth.uid == uid
        && firestore.exists(/databases/(default)/documents/admins/$(request.auth.uid))
        && request.resource.size < 1024 * 1024
        && request.resource.contentType == 'image/jpeg';
      allow delete: if request.auth != null
        && request.auth.uid == uid
        && firestore.exists(/databases/(default)/documents/admins/$(request.auth.uid));
    }
  }
}
